# 真实进度审计与未来七天执行计划

审计日期：2026-09-02（Asia/Singapore）

## 基于实际证据的当前进度

- OpenArm 官方 v2 模型：已在 Windows 下通过无界面模型加载、受限程序化运动、关节与执行器清点以及图像渲染测试。
- Wuji Hand 官方流程：已在 WSL2 中将预录的 `21×3` 手部关键点重定向为有限值的 20 维关节轨迹。目前检查的是第一代 Wuji Hand 左手模型；实验室真实硬件的代际以及是否带触觉仍未确认。
- 组合仿真：已移除 OpenArm 官方左侧原装夹爪，并将官方 Wuji 左手模型安装到 `left_ee_control_point`。安装位姿已经配置化，但目前仍是通过仿真画面确定的估计值，后续必须使用实测的末端工具坐标系到手掌坐标系变换进行替换。
- 统一控制：`MujocoOpenArmWuji` 当前接收 10 维动作，包括 7 维机械臂关节目标和 `open_close`、`pinch`、`spread` 三维手部协同动作。接口会执行执行器范围、关节范围和速度限制，在同一个仿真循环中推进机械臂与灵巧手，并记录对齐后的状态、动作和时间戳。
- 自动化证据：组合模型构建、90 帧双相机控制冒烟测试、压缩记录文件、确定性回放、运行报告、动画以及 5 项单元与集成测试均已通过。
- 尚未完成：LeRobot `Robot` 子类及插件封装、LeRobotDataset 转换、操作任务场景和成功判定器、真实硬件通信协议以及任何学习策略。

## 未来七天安排

### 第 1 天——巩固 Milestone 1 交付物

- 增加具名关节与执行器清单断言，以及安装位姿的回归测试元数据。
- 使用固定相机分别渲染张开、闭合、捏取和手指展开姿态，同时保留成功与失败证据。
- 验收标准：通过一个干净的一键命令完成重新构建、控制和测试，接口维度稳定，报告能够重复生成。
- 求职价值：证明具备 MJCF 模型组合、坐标系分析和安全动作设计能力。

### 第 2 天——相机与回放接口

- 状态：已于 2026-09-03 完成。
- 在 MuJoCo 后端中增加前视和腕部 RGB 观测，并明确图像尺寸与数据类型规范。
- 实现 30 Hz 记录文件的确定性回放，比较回放动作和时间戳。
- 验收标准：保存的 episode 能够完整回放，所有模态的样本数量严格一致。

### 第 3 天——LeRobot 兼容组合层

- 状态：已于 2026-09-03 完成 Mock 与 MuJoCo adapter 契约；数据集写入将在任务场景建立后验收。
- 检查已固定版本中的 LeRobot `Robot`、`openarm_follower` 和 `bi_openarm_follower` 接口。
- 使用组合设计实现独立插件 `lerobot_robot_openarm_wuji` 的基本结构，支持 Mock 和 MuJoCo 后端，并保持 RealBackend 不执行任何未经确认的硬件操作。
- 验收标准：配置发现与导入测试通过，`connect`、`get_observation`、`send_action` 和 `disconnect` 接口契约测试通过。

### 第 4 天——Reach–Grasp–Lift 任务场景

- 添加桌面、随机位置方块、固定前视相机、腕部相机、碰撞分组和显式随机种子。
- 在开始学习之前，加入脚本化的接近、抓取和抬升控制，以验证场景物理行为。
- 验收标准：场景可确定性重置，能够检查接触，并输出机器可读的成功或失败标签。

### 第 5 天——Episode 数据格式与记录器

- 定义稳定的 observation/action 字段、任务文本、episode 编号、时间戳、经过安全限制后实际发送的动作以及任务结果。
- 增加保存、加载、可视化和回放测试，并记录各字段单位和坐标系定义。
- 验收标准：多个脚本化 episode 可以完成保存和重新加载，且不存在维度或时间对齐漂移。

### 第 6 天——LeRobotDataset 转换冒烟测试

- 根据已固定的 LeRobot commit 创建隔离的策略环境。
- 转换一个小型数据集，通过 LeRobot 加载并检查数据特征，运行 100 步数据管线冒烟测试；此阶段暂不进行完整训练。
- 验收标准：从干净命令开始，数据集验证和 DataLoader 迭代均成功。

### 第 7 天——量化评测与作品集检查点

- 在使用固定随机种子的不同方块位置上运行至少 30 次脚本化试验，统计成功、抓空、掉落、碰撞、任务时长和控制延迟。
- 编写简短的英文 README 章节，制作系统架构图初稿，保留一个成功视频和一个失败视频，并整理技术决策与面试讲解要点。
- 验收标准：所有结果均由保存的日志自动生成，而不是手工填写；同时明确记录当前限制。
